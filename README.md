## 架构亮点 (Showcase)

本项目开源了基础引擎部分，供 Android 开发者学习：

* Spring UI 引擎：抛弃传统 XML 布局与补间动画，基于 `androidx.dynamicanimation` 构建的纯代码、全物理反馈 UI 框架。
* 字典驱动解耦：展示了如何通过接口将业务逻辑与底层版本特征进行彻底的物理隔离。
* Spatial 3D Touch：纯数学矩阵计算实现的空间倾斜与液态拉伸交互引擎。
